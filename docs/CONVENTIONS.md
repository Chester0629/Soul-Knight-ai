# Soul-Knight-ai - Conventions & Rules

The working agreement for this repo. Pairs with `docs/HARNESS.md` (the three-layer
build harness) and `CLAUDE.md` / `AGENTS.md` (the GitNexus protocol). Most of
these are enforced automatically - see [Enforcement](#enforcement).

## Build & run (Windows + Visual Studio 2022)

```bash
cmake -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Debug
cmake --build build --config Debug                      # SoulKnight.exe
cmake --build build --config Debug --target Tests       # PTSD engine unit tests
cmake --build build --config Debug --target SoulKnightTests  # game-layer unit tests
ctest --test-dir build -C Debug                         # run all tests
./build/Debug/SoulKnight.exe                            # WASD move, mouse aim, LMB shoot, ESC quit
```

- `-DCMAKE_BUILD_TYPE=Debug` is **required** (the multi-config VS generator leaves
  the type empty otherwise, and the root `CMakeLists.txt` `FATAL_ERROR`s on non-Debug;
  `RESOURCE_DIR` is a relative-path WIP).
- CMake >= 4.0 needs the `CMAKE_POLICY_VERSION_MINIMUM` shim (already in
  `CMakeLists.txt`) so legacy deps (SDL2/glew/glm) configure.

## Architecture rules

1. **PTSD is a vendored, in-tree engine** added via `add_subdirectory(PTSD)` in the
   root `CMakeLists.txt`. **Never** pull it with `FetchContent` + `SOURCE_DIR=PTSD`:
   a clean reconfigure re-extracts the archive **over** our local engine edits and
   silently wipes them. (This actually happened; see the git history.)
2. **Generic, reusable systems sink into the engine** (`PTSD/include`, `PTSD/src`)
   under `Util::` / `Core::` / `Physics::`. **Game-specific logic stays in this repo**
   (`include/`, `src/`) under the `Game::` namespace.
3. **Data-driven content.** Game balance/content comes from `Resources/data/*.json`,
   generated by `tools/` from the `1.07/` Unity dump. Scaling content should mean
   "add data, not engineering" - extend the tables + assets, not the systems.
4. **Register every new file.** New engine files -> `PTSD/CMakeLists.txt`
   (`SRC_FILES` / `INCLUDE_FILES` / `TEST_FILES`). New game files -> `files.cmake`.
5. **Layout:** `src|include/{data,combat,entities,world,ui,scenes}/`,
   engine tests in `PTSD/test/`, game tests in `test/`.

## Coding standards

- **C++17.** Must compile **warning-clean** under MSVC `/W4` **and**
  `-Wall -Wextra -pedantic`: initialize every member, omit unused parameter names,
  no signed/unsigned mismatch, no narrowing.
- **ASCII-only source.** No em-dashes, smart quotes, or other non-ASCII bytes in
  `.hpp/.cpp/.h/.inl` - they trip MSVC `C4819` under non-UTF-8 code pages (e.g. Big5).
- **Naming** (see `.clang-tidy`): `CamelCase` types/functions/namespaces,
  `camelBack` locals/params, `m_` instance members, `s_` static members,
  `UPPER_CASE` enum constants / global constants / `kFoo` file-scope constants.
- Header guards `NAMESPACE_NAME_HPP`; Doxygen-light comments on public APIs.
- Run `clang-format` (config at repo root) before committing.

## GitNexus protocol (also in CLAUDE.md)

- Run `gitnexus_impact({target, direction:"upstream"})` **before editing any symbol**;
  surface the blast radius, and stop/ask on HIGH/CRITICAL.
- Run `gitnexus_detect_changes()` **before committing**.
- Explore with `gitnexus_query` instead of grepping; the repo is indexed as
  `Soul-Knight-ai`. If a tool reports the index is stale, run `npx gitnexus analyze`.

## Validation gates (each must pass before the next)

`data schema (tools/validate_data.py)` -> `unit tests (ctest)` ->
`build (cmake)` -> `smoke (scene boots without crashing)` -> playtest checklist.

## Assets

- The `1.07/` Unity dump is the source of art/audio/balance and is **git-ignored**.
- `python tools/import_assets.py` copies `1.07/{Sprite,AudioClip,Font}` into
  `Resources/{sprites,audio,fonts}/` (all **git-ignored**) and rebuilds
  `Resources/data/sprite_manifest.json`. Only `Resources/data/*.json` is committed.

## Enforcement

| Rule | Enforced by |
|------|-------------|
| Data tables valid, ASCII-only source, no artifacts staged | git `pre-commit` hook (`.githooks/pre-commit`) |
| No accidental destructive commands (force-push, reset --hard, rm -rf of source) | Claude Code hook (`.claude/settings.json`) |
| Formatting + naming | `.clang-format` / `.clang-tidy` |
| Symbol-level change safety | GitNexus impact analysis (above) |

**Enable the git hook in a fresh clone:**

```bash
git config core.hooksPath .githooks
```
